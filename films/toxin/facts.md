# 《毒药谜题》事实表

每个上屏的年份、人名、数字，出处和把握程度都在这里。核对日期：2026-10-14。

## 一句话论点

你没法靠"想要"就真心打算做一件事：打算是对明天的自己的预言。所以"明天再做"每失约一次，下一次的真心就少一分。要让零点说的话算数，得改明天下午，而不是逼零点的自己。

## 片中的推演（全部是示意，片中写明）

- **"扫描仪读你预见的明天"**：这是把"打算要求你相信自己到时会做"画成了画面，是对 Kavka 论证的一种通俗说法，不是原文。
- **奖励在零点"到账"**：生活里许下决心的那一刻就有的满足感，被画成零点的一笔到账。这是类比，不引用任何研究。
- **读数 / 月相模型**：每晚的"真心读数" r 按近来兑现的情况推算（越近的夜晚越算数）。
  - 起点 r = 0.90（第一晚很乐观）；每过一晚 r ← 0.96·r + 0.04·x，兑现 x = 1，失约 x = 0。
  - 第 1–30 晚全部失约：90 → 86 → 83 → 80 → … → 28（第 30 晚）→ 26（第 31 晚）。
  - 药量 d（0–1，满瓶 = 1）的读数 = r^d：第 31 晚满瓶 26，调到 0.2 瓶是 77。
  - 第 31–60 晚全部兑现，药量按"读数保持在约 78"来定：0.2 → 0.37（第 41 晚）→ 0.63（第 51 晚）→ 约 1 瓶（第 60 晚）。
  - 第 61 晚满瓶读数 78。月亮的亮面比例 = 读数。
- **到账失败**：读数低于 50 时，零点那笔"我要变好了"不再到账（第 16 晚起）。示意。

## 不放进片子的东西

- 没有可靠出处的"多少人许了愿却没做到"之类的百分比。查过 Sheeran 2002 / Orbell & Sheeran 1998 的"inclined abstainers"比例，没能核实具体数字，所以不用。
- "公开目标会降低完成率"（Gollwitzer 等 2009）有重复验证的争议，不用。
